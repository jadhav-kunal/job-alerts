# Action Verbs for Resume Bullets

Always start bullets with a strong past-tense action verb. Choose the most precise verb for the work done.

---

## Tier 1 — Engineering (prefer these for technical bullets)

**Building / Creating**
Built, Architected, Designed, Engineered, Developed, Implemented, Constructed, Launched, Delivered, Deployed

**Improving / Optimizing**
Optimized, Refactored, Redesigned, Reduced, Accelerated, Streamlined, Enhanced, Improved, Upgraded, Cut, Decreased

**Scaling / Migrating**
Scaled, Decomposed, Migrated, Distributed, Modularized, Containerized, Orchestrated

**Automating / Integrating**
Automated, Integrated, Instrumented, Configured, Standardized, Systematized

**Data / Analytics**
Processed, Extracted, Transformed, Indexed, Aggregated, Modeled, Queried, Executed

**Debugging / Reliability**
Diagnosed, Resolved, Prevented, Eliminated, Debugged

---

## Tier 2 — Leadership / Collaboration

Led, Directed, Coordinated, Mentored, Managed, Facilitated, Supervised

---

## Tier 3 — Research / Analysis

Analyzed, Evaluated, Benchmarked, Investigated, Identified, Measured, Researched, Tested

---

## Never Use These Openers

- "Worked on" / "Worked with"
- "Helped" / "Assisted" / "Supported"
- "Was responsible for"
- "Participated in" / "Contributed to" / "Involved in"
- "I" / "We" (never use pronouns)

---

## Verb Tense Rules

- **Past roles**: Always past tense ("Built", "Optimized", "Led")
- **Current role**: Past tense for completed deliverables; present tense acceptable for ongoing ownership
- **Projects**: Past tense if completed, present tense if ongoing and actively maintained
