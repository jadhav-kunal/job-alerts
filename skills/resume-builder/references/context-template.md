# Context Intake Template

When the user hasn't provided enough detail to write strong bullets, present this template and ask them to fill it in. Explain that the more detail they provide, the stronger and more authentic the resume will be.

---

## Instructions for the User

Copy the template below and fill in as much detail as you can for each section. Skip sections that don't apply. More detail = better bullets. You don't need to write in resume language — write naturally, like you're explaining your work to a friend.

## What to Do With the Filled Context

Once the user fills this in:

1. Cross-reference every bullet idea against the filled context — only use what's there
2. Extract concrete metrics from the "Before/After" and scale fields
3. Use plain-language descriptions to identify the strongest technical story for each role
4. Flag anything the user mentioned that might be worth adding to Technical Skills
5. If a metric seems too good to be true (e.g., "99% reduction"), ask the user to confirm before using it

Never invent details not present in the template. If a field is blank, write a bullet without that metric rather than fabricating one.
